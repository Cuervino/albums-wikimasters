# Albums WikiMasters

Projet personnel, fait pour être partagé entre amis : des albums à remplir pour ranger ses cartes WikiMasters par thème. Il n'est pas destiné à être diffusé ni utilisé en dehors de ce cercle.

Le jeu, le nom et les visuels des cartes appartiennent à WikiMasters. Les images et les textes viennent de Wikipédia.
